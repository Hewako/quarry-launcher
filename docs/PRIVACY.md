# Приватность в Lime

Коротко: Lime не собирает статистику, не показывает рекламу и ничего не отправляет
разработчикам. Лаунчер обращается только к сервисам, без которых не работает нужная вам
функция, и хранит данные у вас на компьютере.

## Куда и что уходит

| Сервис | Когда | Что передаётся |
|---|---|---|
| Microsoft, Xbox Live, Minecraft Services | вход и проверка покупки игры | код входа и токены Microsoft; пароль вводится только на сайте Microsoft |
| Mojang (piston-meta, libraries, resources) | установка и запуск игры | запросы файлов игры |
| Ely.by | вход через Ely.by (по вашему выбору) | логин и пароль — только на authserver.ely.by, пароль не сохраняется |
| Modrinth | каталог, установка и обновление модов и сборок, опознание файлов | поисковые запросы, версия игры, хэши файлов модов (чтобы узнать, что это за мод) |
| CurseForge | каталог CurseForge (в сборках с ключом) | поисковые запросы, версия игры |
| Adoptium (Temurin) | если нужной Java нет | запрос нужной версии Java |
| GitHub | проверка новой версии Lime и свежих правил Mod Doctor | обычный запрос страницы; можно выключить в настройках |
| Серверы Minecraft | проверка серверов из вашего списка | стандартный запрос статуса (как в самой игре) |

Каждый запрос подписан как `Hewako/quarry-launcher/<версия>` — так требуют правила API
Modrinth.

## Что хранится на компьютере

- **Токены входа** — только в защищённом хранилище системы (Связка ключей macOS,
  Диспетчер учётных данных Windows, Secret Service в Linux), не в файлах.
- **Профили, моды, миры, снимки, бэкапы, логи** — в папке данных Lime (`~/.quarry`).
- **Логи и отчёты поддержки** проходят маскирование ещё при записи: токены, путь к
  домашней папке и IP-адреса заменяются метками. В режиме стримера скрывается и ник.

## Отчёт для поддержки

Отчёт собирается только по вашему нажатию, перед сохранением вы видите его содержимое
и сами решаете, кому его отправить. Сам лаунчер его никуда не отправляет.

## Как удалить свои данные

1. Выйдите из аккаунтов на экране «Аккаунты» — токены удалятся из хранилища системы.
2. Удалите папку данных Lime (`~/.quarry`) — уйдут профили, миры, логи и настройки.
