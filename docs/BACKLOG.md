# Отложено (P2/P3 и известные ограничения)

Источник приоритетов — `../Information for Claude/Разбор_плана_v1.3_глазами_игрока.md`.

## Известные ограничения

- **Vanilla 1.13–1.17.1 на современных macOS не запускается** (MCL-15163: игра падает на
  `glfwSetWindowIcon`, GLFW из LWJGL 3.3 сообщает об ошибке). Lime не начинает такой запуск и
  объясняет выход; Fabric 1.14–1.17.1 работает с модом MacOS LWJGL Fix (Mod Doctor требует его).
  Проверено 22.10.2026: GLFW 3.3 с LWJGL 3.3.1 не работает (нет `glfwInitAllocator`). Остаются
  Java-агент или пропатченная сборка GLFW — свой бинарный код, отложено.
- **Forge** — процессоры установщика старых версий (маппинги MCP/Mojang); механизм NeoForge
  переиспользуется, но объём тестов большой. После v1.0 (план, Приложение А).

## Не делаем

- Тест-запуск в одноразовой копии профиля (обычный запуск даёт тот же сигнал).
- Семейный, учебный, корпоративный режимы; PIN.
- Группы как уровень наследования настроек (группы — только папки для порядка).

- SRV-записи при пинге берутся через DNS-серверы из системных настроек; если они недоступны напрямую (VPN, частный DNS на macOS), SRV пропускается. Решение — системный резолвер macOS.
- Отчёт для поддержки и отчёт о сборке (`modpack_report`) собираются по-русски и в английском интерфейсе: это файлы для автора, а не сообщения на экране.
- Skin Studio (3D-предпросмотр, перевод 64×32 → 64×64, проверка развёртки) и смена скина/плаща через Minecraft Services — P3 по разбору игрока; сейчас только просмотр.
- Размер профиля на карточке (сейчас — в шапке профиля: считать размеры всех профилей при каждом показе списка дорого).
- Подсветка «точной строки» хука в показе итоговой команды (сейчас — в окне согласия и в событиях запуска).
