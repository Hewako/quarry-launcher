# Отложено (P2/P3 и известные ограничения)

Источник приоритетов — `../Information for Claude/Разбор_плана_v1.3_глазами_игрока.md`.

## Известные ограничения

- **Vanilla 1.14–1.18 на современных macOS.** Игра падает на `glfwSetWindowIcon`
  («Regular windows do not have icons on macOS», MCL-15163). Варианты: предлагать мод-исправление
  для Fabric-профилей (например, «macos lwjgl fix» на Modrinth — проверить источник и лицензию);
  для vanilla — Java-агент, отключающий вызов (оценить риск и поддержку).
- **1.7–1.12 (LWJGL 2) на Apple Silicon** — не проверялось.
- **Forge** — процессоры установщика старых версий (маппинги MCP/Mojang); механизм NeoForge
  переиспользуется, но объём тестов большой. После v1.0 (план, Приложение А).

## P2

- Установка ресурспаков и шейдеров из каталога (поиск уже есть).
- Экспорт профиля в .mrpack.
- Поиск и скачивание через API CurseForge (сейчас — импорт zip и список для ручной загрузки).

- Слои при обновлении модпака (база / мои моды / мои конфиги), трёхстороннее объединение конфигов.
- Полуавтоматический bisect для поиска мода-виновника.
- Сравнение снимков (diff) и сравнение профилей.
- Поиск и обновления через каталог CurseForge (нужен API-ключ).
- Отчёт сборки MODPACK REPORT в Markdown.
- Применение скина к Microsoft-аккаунту.
- Хуки до/после запуска, обёртки gamemode/mangohud.

## P3

- Skin Studio с 3D и конвертацией 64×32 → 64×64.
- Облако и синхронизация, плагины, ИИ-помощник, витрина сборок, локальный сервер.
- Маппинги для версий до 26.1.

## Не делаем

- Тест-запуск в одноразовой копии профиля (обычный запуск даёт тот же сигнал).
- Семейный, учебный, корпоративный режимы; PIN.
- Группы как уровень наследования настроек (группы — только папки для порядка).

- SRV-записи при пинге берутся через DNS-серверы из системных настроек; если они недоступны напрямую (VPN, частный DNS на macOS), SRV пропускается. Решение — системный резолвер macOS.
- Ресурспаки и шейдеры с CurseForge (сейчас каталог CurseForge — только моды).
- Сообщения ядра (ошибки, предупреждения запуска, находки Mod Doctor, разбор крашей) пока только на русском: в английском интерфейсе они остаются русскими. Перевести — через коды сообщений в ядре.
- Skin Studio (3D-предпросмотр, перевод 64×32 → 64×64, проверка развёртки) и смена скина/плаща через Minecraft Services — P3 по разбору игрока; сейчас только просмотр.
- Размер профиля на карточке (сейчас — в шапке профиля: считать размеры всех профилей при каждом показе списка дорого).
- Подсветка «точной строки» хука в показе итоговой команды (сейчас — в окне согласия и в событиях запуска).
