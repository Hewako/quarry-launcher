# Релизный чек-лист Quarry

Проходить перед каждым тегом `vX.Y.Z`. Установщики собирает GitHub Actions (`release.yml`)
черновиком; публикует релиз владелец. Подписи сертификатом и автообновления нет (решение
владельца), на macOS — ad-hoc подпись пакета.

## До тега

- [ ] CI зелёный на macOS, Windows и Linux для коммита, который пойдёт в релиз
      (`cargo test`, clippy, fmt, `npm run build`, `npm run i18n:check`, `npm run ipc:check`).
- [ ] Версия одна во всех местах: `Cargo.toml` (workspace), `ui/package.json`.
- [ ] `CHANGELOG.md`: раздел «Ещё не вышло» переименован в `X.Y.Z — дата`, сверху новый пустой.
- [ ] Секреты репозитория на месте: `QUARRY_MS_CLIENT_ID` (одобренный Mojang),
      `QUARRY_CURSEFORGE_KEY` (если каталог CurseForge нужен в этой версии).
- [ ] Известные ограничения в README актуальны.
- [ ] Финальный аудит без находок уровня «исправить обязательно» (безопасность, утечка токенов).
- [ ] `cargo audit` — без уязвимостей; `npm audit --omit=dev` (в `ui/`) — без уязвимостей.
- [ ] Лицензии сторонних библиотек приложены к установщикам (MIT/Apache требуют текст лицензии).

## Пробная сборка (rc)

- [ ] Тег `vX.Y.Z-rc.N` → черновик релиза помечен pre-release (лаунчеры игроков его не видят).
- [ ] Собрались все четыре задания: macOS Apple Silicon, macOS Intel, Windows, Linux.
- [ ] macOS: `syspolicy_check distribution Quarry.app` → только «Adhoc Signed App», без
      «Codesign Error» (иначе скачанное из браузера приложение macOS назовёт повреждённым).
- [ ] macOS: приложение из `.dmg` запускается, открывается главная.
- [ ] Linux: зависимости `.deb` покрывают всё, что нужно программе
      (`llvm-objdump -p usr/bin/quarry-ui | grep NEEDED` против `Depends`).
- [ ] Windows: `.exe` — установщик NSIS, `.msi` открывается (проверка на настоящей Windows — владелец).
- [ ] Эталонный сценарий на чистой системе: установка → вход Microsoft → профиль Vanilla →
      запуск до главного меню → выход. macOS — Claude, Windows и Linux — владелец или ВМ
      (план v1.3, Gate 1→2).

## Тег и публикация

- [ ] Тег `vX.Y.Z` на проверенном коммите `main` (тот же, что прошёл rc).
- [ ] Черновик собран, файлы и текст релиза проверены.
- [ ] Владелец публикует релиз. Проверка: в старой версии Quarry появилось «Вышла новая версия».

## Откат

Если после публикации нашлась ошибка, из-за которой игра не запускается или теряются данные:
1. Снять релиз с публикации (вернуть в черновик) — лаунчеры перестанут предлагать его.
2. Исправить, выпустить `vX.Y.Z+1` по этому же чек-листу.
Тег не переписывать: игроки могли уже скачать файлы этой версии.
