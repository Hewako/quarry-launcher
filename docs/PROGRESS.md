# Журнал прогресса Quarry

Единственный источник правды о состоянии работы. Задание — `../Information for Claude/Промпт_для_Claude_Code.md`.

## Текущее состояние

- **Этап:** 2 — аккаунты (этап 1 завершён, см. отчёт ниже).
- **Ветка:** `stage-2-accounts` (от `stage-1-cleanup`).
- **Следующий шаг:** скин и аватар текущего аккаунта; выбор аккаунта по умолчанию; тест «токены не попадают в логи» на уровне всего запуска.

Проверка текущего состояния:

```bash
cargo fmt --all --check && cargo clippy --workspace --all-targets -- -D warnings && cargo test --workspace
cd ui && npm ci && npm run build
cargo build -p quarry-core --features dev-launch && ./target/debug/quarry launch <id>   # запуск без входа (debug)
```

## Этап 1 — починить и очистить ✅ (ветка `stage-1-cleanup`)

### Находки ревью

| # | Находка | Воспроизведено | Итог |
|---|---|---|---|
| 1 | Log4Shell: `logging.client` не читается | да: в 1.16.5/1.12.2 `log4j-core 2.8.1`, поле `logging.client` есть, в команде его не было | logging-конфиг скачивается (SHA-1) и подставляется; golden-тест `log4shell_protection_for_vulnerable_versions`. Для версий без поля (≤1.6.4) log4j нет вовсе — защитные флаги не нужны (проверено по данным) |
| 2 | Поиск Java всегда `"java"` | да, по коду: условие `path != "java"` недостижимо | реальный поиск (JAVA_HOME, PATH, папки ОС, runtimes), проверка версии и архитектуры, выбор с причиной; Java 8 — строго 8; дедупликация по `java.home` |
| 3 | JDK без хэша, zip-slip, первый попавшийся `java` | да | SHA-256 из API Adoptium; безопасная распаковка tar/zip (тесты на `../` и ссылки наружу); детерминированный поиск `bin/java`; Fabric — `sha1` из meta, Quilt — `.sha1` из Maven |
| 4 | Загрузчик: клиент на файл, всё в памяти, `.tmp` | да | общий клиент, потоковая запись с хэшем, повторы с паузой, прогресс, отмена, уникальные временные файлы |
| 5 | Аргументы захардкожены | да: `arguments` не использовались, тройной `if` | сборка по `arguments`/`minecraftArguments` с rules/features, Quick Play, подстановка переменных; `-XstartOnFirstThread` — только из данных версии; golden-тесты 7 версий × 3 ОС |
| 6 | `javaVersion` обязателен, две пары структур, нет `os.version` | да: 1.6.4 не разбирался | поле необязательно (фолбэк 8 только при отсутствии), одна модель библиотек, регулярные `os.version`, `${arch}` |
| 7 | «Играть» разблокируется через 3 с | да, по коду | один запуск на профиль (реестр), события Rust → UI, отслеживание процесса, лог в файл с маскированием, состояния подготовка/игра/завершена/упала |
| 8 | Профили: битый файл ломает список, удаление с мирами | да | битые показываются отдельно; корзина вместо удаления; атомарная запись; зарезервированные имена Windows; перенос старой раскладки без удалений |
| 9 | Ely.by: refresh token, callback, секрет | да | refresh token в keyring; callback терпит лишние соединения, обрабатывает `error=`, таймаут, отмену; секрет не вшит. **Работает ли PKCE без секрета — не проверено**: документация описывает только Website с секретом, а 21.10.2026 сервисы Ely.by отключены (HTTP 503). Вход Ely.by закрыт за Microsoft-аккаунтом с купленной игрой |
| 10 | Токен в командной строке | — | в логи и «точную команду» не попадает (тесты `captures_masked_output_and_exit_code`, golden `…token_only_once`) |

### Не проверено

- Windows и Linux — только через CI (файл готов, не запускался: ничего не пушилось).
- Запуск Vanilla/Fabric **из нативного окна интерфейса** — проверен CLI и предпросмотр UI; окно — см. «Проверить владельцу».

## Допущения

- Версия всех пакетов — `0.1.0` (единый источник `workspace.package.version`).
- Крейт интерфейса переименован `ui` → `quarry-ui` (библиотека `quarry_ui_lib`).
- Папка данных остаётся `~/.quarry`; старая раскладка переносится переименованием при первом открытии.
- Быстрая проверка перед запуском сверяет размер файлов; полная (хэши) — пунктом «Проверить файлы и играть».
- Память по умолчанию 4 ГБ, Xms = Xmx.
- XUID для `--xuid` — «0» (ответ XSTS для Minecraft его не содержит; не подтверждено первоисточником).
- Владение Java Edition — по `product_minecraft`/`game_minecraft`/Game Pass в entitlements; подпись JWT не проверяется (данные получены по TLS от Mojang).

## Проверить владельцу

1. **Секрет Ely.by в локальной истории.** Ветка `main` содержит `client_secret` Ely.by в трёх
   непубликованных коммитах. Перед любым `git push` переставьте `main` на чистую ветку
   (например, `git branch -f main stage-2-accounts`) и **смените секрет в кабинете Ely.by**.
2. **Токен Ely.by в открытом виде** в `~/.quarry/active_account.toml` (записан старой версией).
   Новый код этот файл не читает. Удалите файл и завершите сессию в кабинете Ely.by.
3. Регистрация приложения Microsoft и заявка Mojang — `docs/MICROSOFT_SETUP.md`.
4. Интерфейс: `cd ui && npm run tauri dev -- --features dev-launch` → «Играть» в профиле Fabric Test.
   Ожидается: прогресс в верхней строке и под кнопкой, затем «игра запущена», окно Minecraft;
   после закрытия игры — статус «запуск успешен».
