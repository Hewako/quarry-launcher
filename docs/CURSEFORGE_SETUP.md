# Каталог CurseForge: как подключить ключ API

Каталог CurseForge в Quarry работает только с ключом API. Ключ **не хранится в коде и в
репозитории**: он подставляется при сборке из переменной окружения `QUARRY_CURSEFORGE_KEY`.
Без ключа лаунчер работает как обычно, просто в каталоге нет переключателя «CurseForge».

## 1. Получить ключ

1. Войдите на <https://console.curseforge.com/> (нужен аккаунт CurseForge / Overwolf).
2. Создайте организацию и проект, запросите ключ API для приложения (Quarry — открытый
   лаунчер Minecraft, моды скачиваются с разрешения авторов).
3. Скопируйте ключ. Никуда его не вставляйте в код и не коммитьте.

## 2. Собрать локально с ключом

```bash
cd ui && QUARRY_CURSEFORGE_KEY='ваш-ключ' npm run tauri build
```

Для разработки — то же самое с `npm run tauri dev`. Проверка: в каталоге модов появился
переключатель «Modrinth | CurseForge».

## 3. Сборки на GitHub

В репозитории: **Settings → Secrets and variables → Actions → New repository secret**,
имя `QUARRY_CURSEFORGE_KEY`, значение — ключ. Сборка релиза берёт ключ оттуда
(`env: QUARRY_CURSEFORGE_KEY: ${{ secrets.QUARRY_CURSEFORGE_KEY }}`); в логах GitHub
он скрыт.

## Важно знать

- Ключ попадает внутрь собранной программы, и при желании его можно оттуда достать. Так
  устроены все открытые лаунчеры с CurseForge; если ключ начнут использовать во вред,
  его можно отозвать в консоли и выпустить новый.
- Некоторые авторы запрещают скачивание своих модов сторонними лаунчерами (у файла нет
  ссылки на скачивание). Quarry это уважает: он не скачивает такой файл в обход, а
  объясняет, где скачать его вручную, после чего файл можно перетащить в окно.
- Скачивание идёт только с CDN CurseForge (`*.forgecdn.net`) и с проверкой SHA-1.
- Обновления модов, установленных с CurseForge, пока проверяются только через Modrinth
  (по хэшу файла); отдельная проверка по CurseForge — в планах.
