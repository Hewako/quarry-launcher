# Что нового в Quarry

Здесь простыми словами написано, что появилось, что исправлено и что убрано.
Технические подробности — в описаниях коммитов, правила оформления — в [docs/COMMITS.md](docs/COMMITS.md).

## Ещё не вышло (будет версией 0.1)

### Добавлено

- **Любая версия Minecraft из официального списка**, включая новые 26.x. Список берётся
  у Mojang; снапшоты включаются переключателем, есть поиск.
- **Загрузчики модов Fabric, Quilt и NeoForge.** Лаунчер ещё до скачивания проверяет, что
  загрузчик подходит к выбранной версии игры, и по умолчанию ставит последнюю стабильную версию.
- **Нужная Java подбирается сама.** Лаунчер берёт ровно ту версию Java, которая нужна игре
  (как официальный лаунчер), ищет её на компьютере, а если не находит — скачивает и проверяет.
  Почему выбрана именно эта Java, написано на экране.
- **На Mac с Apple Silicon** используется родная Java, а если её нет — версия для Intel
  через Rosetta. Для версий 1.13–1.18 лаунчер сам подставляет более новую библиотеку
  окна (LWJGL 3.3.1), без которой игра на современных macOS не может открыть окно.
- **Вход через Microsoft с проверкой покупки игры.** Заработает после того, как Mojang одобрит
  приложение (инструкция для владельца — [docs/MICROSOFT_SETUP.md](docs/MICROSOFT_SETUP.md)).
- **Вход через Ely.by логином и паролем** — только если в лаунчере уже есть Microsoft-аккаунт
  с купленной игрой. Пароль никуда не сохраняется. Ely.by работает только на совместимых серверах.
- **Быстрый запуск:** сразу в нужный мир или сразу на сервер.
- **Экран «Логи и краши»:** ошибки подсвечены, есть поиск и копирование. Токены, путь к
  домашней папке и IP-адреса скрываются ещё до записи в файл.
- **На карточке профиля видно, как прошёл последний запуск:** «запуск успешен», «упал»,
  «не запустился» — со временем.
- **Память и Java для каждого профиля.** У каждой настройки видно, откуда взялось значение
  (профиль, сборка или общие настройки), и её можно сбросить.
- **Показ точной команды запуска** — без токена, чтобы можно было разобраться в проблеме.
  Можно посмотреть и до запуска: кнопка «Показать итоговую команду» в настройках профиля.
- **Моды из каталога Modrinth прямо в лаунчере.** Поиск показывает только то, что подходит к
  версии игры и загрузчику; обязательные зависимости ставятся сами (например, Sodium для Iris).
- **Обновление модов с предпросмотром:** видно, что и до какой версии обновится, можно снять
  галочки. Стабильным модам не предлагаются бета-версии.
- **Снимки и откат.** Перед каждой установкой, обновлением и удалением мода лаунчер сам
  сохраняет снимок (моды, их настройки, options.txt). Откатиться — одна кнопка, и откат тоже
  можно отменить. Можно сравнить снимок с текущим состоянием и закрепить важный снимок.
- **Бэкапы миров** одной кнопкой; хранятся 5 последних для каждого мира.
- **Миры видны по-человечески:** название, версия игры, режим, размер, когда играли и список
  бэкапов. Любой бэкап можно вернуть кнопкой «Восстановить» — текущий мир при этом не
  удаляется, а сначала сам сохраняется в бэкап.
- **Миры защищены автоматически.** Если моды менялись после прошлой игры, перед запуском
  делается бэкап последнего мира. Если мир сохранён в более новой версии игры, чем
  запускается, лаунчер предупреждает и делает бэкап. Перед удалением или выключением мода,
  который добавляет блоки, измерения или генерацию, тоже делается бэкап. Бэкап после выхода
  из игры и бэкап по расписанию (каждый день, раз в 3 дня, раз в неделю) включаются в
  настройках. Если добавлен мод, меняющий генерацию мира, лаунчер предупреждает, что
  совместимость с уже созданными мирами не проверена.
- **Вкладка «Серверы»:** тот же список, что в игре, с проверкой — онлайн, игроки, версия,
  задержка и описание сервера. «Играть» запускает игру и сразу подключает к серверу.
  Серверы можно добавлять, менять, переставлять и убирать.
- **Порядок в профилях:** поиск, сортировка (недавние, по имени, по версии, новые), избранное
  (показывается первым), группы с фильтром, архив (профиль скрыт, файлы на месте), заметка
  и цвет значка — на новой вкладке «Профиль».
- **Копия профиля** — целиком или частично: можно взять моды, настройки, ресурспаки и миры.
- **Перенос настроек из другого профиля:** управление и графика (options.txt), список
  серверов, ресурспаки, шейдеры, настройки модов и миры (копией — свои миры не заменяются).
  Перед переносом сохраняется снимок.
- **Папку игры можно перенести на другой диск** и вернуть обратно. Исходная папка удаляется
  только после проверки, что копия полная.
- **Видно, сколько места занимает профиль:** миры, моды, ресурспаки, скриншоты, снимки, бэкапы.
- **Импорт:** инстансы из Prism Launcher и MultiMC, сборки .mrpack с Modrinth, zip-сборки
  CurseForge (моды, которые CurseForge разрешает скачивать только через сайт, перечисляются
  списком), а также папка официального лаунчера — без копирования.
- **Mod Doctor проверяет сборку до запуска:** нехватка модов, неподходящие версии, дубли, моды
  для другого загрузчика, несовместимости, о которых предупредили авторы. Если игра точно
  не запустится, лаунчер скажет почему сразу, а не после минуты загрузки. У каждого
  вывода видно основание. У мода три состояния: «конфликтов не найдено», «есть
  предупреждение», «блокирует запуск».
- **Разбор краша:** после падения лаунчер называет вероятную причину (мод, нехватка памяти,
  драйвер видеокарты), показывает строки лога, на которых это основано, и уверенность;
  предлагает действие — выключить мод, запустить без модов, добавить память.
- **Безопасный запуск** — игра без модов; моды возвращаются после выхода.
- Журнал изменений модов в каждом профиле.
- Профили можно показывать карточками или компактным списком.
- Тёмная и светлая тема.
- Аватар аккаунта по текущему скину.

### Изменено

- **Удалённый профиль уходит в корзину** вместе с мирами, а не стирается навсегда.
  Вернуть можно, перенеся папку обратно.
- Папка данных `~/.quarry` сама переходит на новую раскладку при первом запуске — ничего
  не удаляется и не перезаписывается.
- Кнопка «Играть» больше не разблокируется раньше времени: один профиль нельзя запустить дважды.
- Вместо системных окошек — свои понятные диалоги.

### Исправлено

- Лаунчер скачивал Java заново при каждом запуске, даже если она уже была.
- Совсем старые версии (1.6.4 и более ранние) не открывались.
- Один повреждённый профиль ломал весь список профилей.

### Убрано

- **Запуск без аккаунта.** Играть можно только с купленной Minecraft: Java Edition. Для отладки
  разработчиками есть отдельная сборка, в выпуск она не попадает.

### Безопасность

- Старые версии игры (например, 1.16.5) запускались без защиты от уязвимости Log4Shell —
  теперь защита включается всегда, когда версия её предусматривает.
- Скачанные файлы (Java, библиотеки модов) проверяются на целостность; повреждённый или
  подменённый файл не будет использован.
- Архивы распаковываются так, что файл из архива не может попасть за пределы своей папки.
- Секрет приложения Ely.by убран из кода; токены хранятся только в защищённом хранилище системы
  (Связка ключей на Mac, Диспетчер учётных данных на Windows).

### Пока не работает

- **Обычные (без модов) версии 1.14–1.18 на современных macOS.** Окно теперь создаётся, но
  игра падает, пытаясь поставить иконку окна — это ошибка самой игры, Mojang исправила её
  только в 1.19. Решение — небольшой мод для Fabric; лаунчер научится предлагать его вместе
  с каталогом модов.

### Пока не проверено

- Работа на Windows и Linux — проверяется автоматически на GitHub, вживую не запускалась.
- Вход Microsoft — ждёт одобрения приложения Mojang.
- Вход Ely.by — сервисы Ely.by были временно недоступны во время разработки.
- Импорт из Prism и zip CurseForge на настоящих файлах игроков (проверено на тестовых данных);
  импорт .mrpack проверен на сборке Fabulously Optimized.
- Запуск версий 1.7–1.12 (старая библиотека окна LWJGL 2) на Mac с Apple Silicon.
